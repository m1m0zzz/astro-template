# mimoz's Astro Starter Kit

```sh
npm create astro@latest -- --template m1m0zzz/astro-template/lp
```

```sh
npm create astro@latest -- --template m1m0zzz/astro-template/blog
```

## ✨ Basic Features

- Tailwind CSS
- astro/sitemap
- OGP template
- ESLint + Prettier
- husky + lint-staged
- VSCode config
- additional tools: nvm (Node=24), editorconfig, cspell, renovate
