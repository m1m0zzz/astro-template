この記事はスタイル確認用のサンプルです。見出しが多いので、目次の動きも一緒に確認できます。

## 見出し

`##`（h2）と `###`（h3）が目次に載ります。載せる範囲は `src/config.ts` の
`BLOG.tocDepth` で変えられます。

### h3 の見出し

h3 は目次の中で 1 段下げて表示されます。

## 文字装飾

**太字**、_斜体_、`インラインコード`、~~打ち消し線~~、
それから[リンク](https://astro.build)が使えます。

> 引用です。
> 複数行にわたって書けます。

## リスト

- 箇条書き
- の項目
  - ネストした項目

1. 番号付きリスト
2. の項目

## コードブロック

コードブロックの右上にカーソルを合わせるとコピーボタンが出ます。
ライトテーマとダークテーマで配色が切り替わります。

```ts
export function greet(name: string): string {
  return `Hello, ${name}!`
}
```

```sh
npm run dev
```

| 記法    | 用途           |
| ------- | -------------- |
| `##`    | 見出し（h2）   |
| `- `    | 箇条書き       |
| ` ``` ` | コードブロック |
