## コマンド

```sh
npm run dev        # 開発サーバーを起動
npm run build      # 本番ビルド（astro check + astro build）
npm run preview    # ビルド結果をローカルでプレビュー
npm run lint       # ESLint（--fix）
npm run format     # Prettier（--write）
npm run check      # lint + format をまとめて実行
```

## スタイリング

- ESLintとPrettierの設定に従う
- アイコンは [`@lucide/astro`](https://lucide.dev/) を使用する

## タスク完了チェックリスト

作業を完了する前に、以下を必ず実行・確認すること:

1. `npm run check`（lint + format）を実行し、エラーがないこと
2. `npm run build` が成功すること
